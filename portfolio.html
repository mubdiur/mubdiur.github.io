I maintain a small collection of local web apps: developer tools and an in-browser IDE, free and offline-ready. This site is fully static — no server, no tracking, no sign-up.

01 / StackWhat this site runs

Static site

  • No server, no build, no framework — open index.html directly, deploy from GitHub Pages
  • Vanilla JS + one stylesheet, self-hosted JetBrains Mono, zero CDN requests
  • Offline shell via service worker precache; tool and IDE engines join the runtime cache on use

WebAssembly core

  • Rust no_std core: MD5, SHA-1/256/384/512, HMAC, CRC32, QR encoder, DER parser
  • Lazy-loaded — only hash/QR tools fetch the 645 KB core

In-browser IDE

  • 8 languages: JavaScript, Python, C, C++, C#, Java, Go, Rust — vendored engines, nothing from a CDN
  • Engines persist in Cache Storage after first run; editor state in localStorage
  • stdin: live for JavaScript, type-ahead for Python/C/C++/Rust; unsupported for Go/C#/Java
